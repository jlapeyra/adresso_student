# ADReSSo Student — Multimodal Alzheimer Detection via Knowledge Distillation

Student model for the TFM project **"Multimodal Alzheimer Detection via Cross-Dataset Knowledge Distillation"**.

The Student learns to detect Alzheimer's disease from speech (audio + transcription + clinical data) using soft labels generated by a Teacher model trained on MRI brain scans (ADNI dataset).

## Model Architecture

```
┌─────────────────────────────────────────────────────────────────────┐
│  AUDIO  (.wav, 16 kHz)                                              │
│    → Wav2Vec2-base (facebook/wav2vec2-base)                         │
│      CNN extractor + layers 0-7: FROZEN                             │
│      Transformer layers 8-11:   TRAINABLE  (4 layers)              │
│      SpecAugment (time masking, p=0.1, train only)                  │
│      → Mean pooling over time                                       │
│      → Linear(768→256) + LayerNorm + GELU + Dropout(0.1)           │
│      OUTPUT: (B, 256)                                               │
│                                                                     │
│  TEXT  (Whisper transcription)                                      │
│    → RoBERTa-base (roberta-base)                                    │
│      Embeddings + layers 0-7:  FROZEN                               │
│      Transformer layers 8-11:  TRAINABLE  (4 layers)               │
│      → [CLS] token                                                  │
│      → Linear(768→256) + LayerNorm + GELU + Dropout(0.1)           │
│      OUTPUT: (B, 256)                                               │
│                                                                     │
│  CLINICAL  [MMSE_norm, AGE_norm, PTGENDER_enc]                      │
│    → LayerNorm(3)                                                   │
│    → Linear(3→64) + GELU + Dropout(0.2)                            │
│    → Linear(64→128) + GELU + Dropout(0.1)                          │
│    → Linear(128→256) + LayerNorm + GELU                            │
│      OUTPUT: (B, 256)                                               │
│                                                                     │
│  Learned missing-modality embeddings: 3 × Parameter(1, 256)        │
└─────────────────────────────────────────────────────────────────────┘
         ↓  Stack → (B, 3, 256)
         
┌─────────────────────────────────────────────────────────────────────┐
│  FUSION TRANSFORMER                                                 │
│    TransformerEncoder × 2 layers:                                   │
│      d_model=256, nhead=4, dim_ffn=512                              │
│      activation=GELU, dropout=0.1                                   │
│      norm_first=True  (Pre-LayerNorm, more stable on small N)       │
│      batch_first=True, no positional encoding                       │
│    Masking of absent modality tokens                                │
│    → Masked mean pooling → (B, 256)                                 │
└─────────────────────────────────────────────────────────────────────┘
         ↓
┌─────────────────────────────────────────────────────────────────────┐
│  DUAL CLASSIFIER HEADS  (separate paths, isolated gradients)        │
│                                                                     │
│  Hard path:  Linear(256→128) + GELU + Dropout(0.1)                 │
│              → Linear(128→2)  → logits_hard                         │
│              Loss: CrossEntropy(logits_hard, y_real)                │
│                                                                     │
│  Soft path:  Linear(256→128) + GELU + Dropout(0.1)                 │
│              → Linear(128→2)  → logits_soft                         │
│              Loss: KL-div(log_softmax(logits_soft/T), P_teacher)    │
└─────────────────────────────────────────────────────────────────────┘
```

**Approximate trainable parameters:** ~23–32 M

## Knowledge Distillation

### Loss Function

Current default: `--kd-method feature`.

Feature-based KD aligns the Student fused 256-d multimodal embedding with the
Teacher frozen 256-d `link_token` embedding exported in
`adni_teacher/outputs/teacher_embeddings.csv`. Both vectors are projected to a
shared space before the alignment loss:

```
z_s = Linear(student_embedding)
z_t = Linear(teacher_embedding)
L_feature = 1 - cosine(normalize(z_s), normalize(z_t))
L_total = alpha * L_hard + lambda_feat * L_feature
```

The old response-based KL objective is still available with
`--kd-method response`, and both objectives can be combined with
`--kd-method both`.

Legacy response-KD objective:

```
L_total = α · L_hard + β · L_distill · T²

α = 0.6   (CrossEntropy weight)
β = 0.4   (KL-divergence weight)
T = 3.0   (temperature)

L_hard    = CrossEntropy(logits_hard, y_real)  with label_smoothing=0.05
L_distill = KL-div( log_softmax(logits_soft / T),  P_binary )
```

### MCI Collapse (MCI → AD)

The Teacher produces 3-class soft labels `[P(CN), P(MCI), P(AD)]`.
ADReSSo only has binary labels (HC / AD), so Teacher probs are collapsed to binary **before** the KL-div:

```
P(HC) = P(CN)
P(AD) = P(MCI) + P(AD)
```

**Rationale:** The Teacher was trained on LMCI/MCI/HMCI as a spectrum towards AD (not as an intermediate healthy state). Clinically, MCI is a prodromal stage of Alzheimer's, closer to AD than to healthy controls. Collapsing MCI → HC would hide diagnostic signal.

### Soft Labels

Generated by `adni_teacher` at temperatures T=1, 2, 3. Two generation strategies available:

**Single checkpoint** (via `adresso_softlabels/src/generate.py`):

| File | Temperature | Description |
|------|------------|-------------|
| `adresso_soft_labels_T1.csv` | T=1.0 | Sharp predictions |
| `adresso_soft_labels_T2.csv` | T=2.0 | Moderate smoothing |
| `adresso_soft_labels_T3.csv` | T=3.0 | Default — recommended |

**Ensemble** (via `adni_teacher/src/eval/ensemble_inference.py --mode softlabels`, recomendado):

| File | Temperature | Description |
|------|------------|-------------|
| `adresso_ensemble_soft_labels_T1.csv` | T=1.0 | Ensemble — menor varianza entre checkpoints |
| `adresso_ensemble_soft_labels_T2.csv` | T=2.0 | Ensemble — recomendado para KD |
| `adresso_ensemble_soft_labels_T3.csv` | T=3.0 | Ensemble — más suave |

La **temperatura calibrada T*** se obtiene con `adni_teacher/src/eval/temperature_scaling.py`
y se guarda en `adni_teacher/outputs/calibration/calibration.json`. Usarla como temperatura de
generación en lugar de T=3 mejora la calibración de las soft labels (ECE).

Columns: `subject_id, dx, mmse, age, sex, subset, has_audio, prob_CN, prob_MCI, prob_AD, pred_class, confidence, entropy`

## Dataset

**ADReSSo 2021 Challenge** — Diagnosis track

| Split | N subjects | HC | AD |
|-------|-----------|----|----|
| Train | ~116 | ~54 | ~62 |
| Val   | ~25  | ~11 | ~14 |
| Test  | ~25  | ~11 | ~14 |
| **Total with audio** | **166** | **79** | **87** |

> The challenge test-dist (71 subjects) has **no audio** and is excluded.
> Splits are stratified (70 / 15 / 15) on the 166 subjects with audio.

### Data Sources

| Data | Path |
|------|------|
| Audio (.wav) | `/home/usuaris/veussd/roger.esteve.sanchez/adresso/ADReSSo21/diagnosis/train/audio/{cn,ad}/` |
| Whisper transcriptions | `tfm_alzheimer/data_processed/adresso/transcriptions_whisper.csv` |
| Clinical features (normalised) | `tfm_alzheimer/data_processed/adresso/adresso_enriched.csv` |
| Teacher soft labels | `adresso_softlabels/outputs/adresso_soft_labels_T3.csv` |

### Clinical Features

3 features shared between ADNI (Teacher) and ADReSSo (Student):
- `MMSE_norm` — Mini-Mental State Examination (z-score, ADNI stats)
- `AGE_norm` — Age at visit (z-score, ADNI stats)
- `PTGENDER_enc` — Sex (0=male, 1=female)

### Audio Augmentation (train only)

| Augmentation | Parameters | Rationale |
|-------------|-----------|-----------|
| Random gain | ±3 dB | Simulates mic volume variation |
| Gaussian noise | SNR 30–40 dB | Simulates mic quality variation |
| Synthetic RIR | delay 1–8 ms, decay 0.10–0.25 | Simulates room acoustics |

**Excluded intentionally:** time stretching, pitch shifting, silence removal — these alter speech rate and pauses, which are diagnostic features for Alzheimer's.

## Training Configuration

| Hyperparameter | Value |
|----------------|-------|
| Epochs | 50 |
| Batch size | 8 (grad_accum=2 → effective B=16) |
| LR pretrained (Wav2Vec2/RoBERTa) | 1e-5 |
| LR new layers (fusion, heads, clinical) | 5e-5 |
| Weight decay | 0.01 |
| Gradient clipping | 1.0 |
| Scheduler | Warmup (10 ep) + Cosine Decay |
| Early stopping | patience=20, monitor=val_loss |
| Mixed precision | AMP fp16 |
| Modality dropout | p=0.2 per modality (train only) |
| Augmentation factor | ×2 (aug-factor=2) |
| Weighted sampler | Yes (balances HC/AD imbalance) |

## Ablation Experiments

| Name | Modalities | KD | Description |
|------|-----------|-----|-------------|
| `audio_only` | Audio | No | Baseline 1 — Wav2Vec2 unimodal |
| `text_only` | Text | No | Baseline 2 — RoBERTa/Whisper unimodal |
| `multimodal_no_kd` | Audio+Text+Clinical | No | Baseline 3 — hard CE only |
| `multimodal_kd` | Audio+Text+Clinical | **Yes** | **Proposed** — full KD |

The delta between `multimodal_no_kd` and `multimodal_kd` measures the contribution of cross-modal knowledge distillation.

### Metrics Reported

- Accuracy, Balanced Accuracy
- Macro F1-score
- Macro AUROC (binary)
- Cohen's Kappa
- Sensitivity (AD recall), Specificity (HC recall)

## Quick Start

### 1. Install dependencies

```bash
cd knowledge_distillation/adresso_student

python3 -m venv .venv
source .venv/bin/activate

# PyTorch with CUDA 12.1 (cluster)
pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu121

pip install -r requirements.txt
```

### 2. Verify installation (no GPU needed)

```bash
python train.py --dry-run
```

Expected output:
```
Fusion Transformer: (8, 3, 256) -> (8, 256)
KD loss: total=X.XXXX hard=X.XXXX distill=X.XXXX
Backward OK ✓
MCI->AD collapse check:
  P(HC) = P(CN)  |  P(AD) = P(MCI) + P(AD)
```

### 3. Train (single run)

```bash
python train.py \
  --ablation multimodal_kd \
  --kd-method feature \
  --epochs 50 \
  --batch-size 8 \
  --augment-train \
  --aug-factor 2
```

### 4. 5-fold cross-validation

```bash
python train.py \
  --ablation multimodal_kd \
  --cv \
  --n-folds 5 \
  --augment-train \
  --aug-factor 2
```

### 5. All ablations + CV

```bash
python train.py --ablation all --cv
```

### 6. Submit to SLURM cluster

```bash
sbatch scripts/train_student.sbatch
```

Monitor:
```bash
squeue -u $USER
tail -f logs/train_student.log
tensorboard --logdir logs/tb/
```

## Key Design Decisions

| Decision | Choice | Rationale |
|----------|--------|-----------|
| Partial fine-tuning | Last 4 layers of Wav2Vec2/RoBERTa | N=166 is very small; full fine-tuning would overfit |
| Fusion | Pre-LN Transformer (2L, 4H) | More stable than concatenation; Pre-LN better than Post-LN on small data |
| No positional encoding | None | Modalities have no inherent order |
| MCI collapse | MCI → AD | Teacher trained on LMCI/MCI/HMCI as AD spectrum |
| KD temperature | T=3.0 | Standard from Hinton et al. (2015); soft enough to capture inter-class structure |
| Loss weights | α=0.6, β=0.4 | β<0.5 avoids over-regularisation on small datasets (Kwak et al. 2024) |
| Separate classifier heads | Hard + Soft | Isolates gradients from CE and KL-div losses |
| Modality dropout | p=0.2 | Prevents clinical features from shortcutting audio/text learning |
| Weighted sampler | Yes | Compensates HC/AD imbalance (79 HC vs 87 AD) |
